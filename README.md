# Nova — Personal Digital Space

Nova is a personal digital space designed to bring essential personal tools and information together in one application.

## Features

- User registration and sign-in
- Password hashing using Argon2
- Session-based authentication
- SQLite database integration
- File storage
- Encrypted vault functionality using browser-side encryption
- Contact form

## Technology Stack

### Backend
- Python
- FastAPI
- SQLite
- Argon2 password hashing

### Frontend
- HTML
- CSS
- JavaScript
- Web Crypto API for browser-side encryption
